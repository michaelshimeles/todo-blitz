# Todo Blitz

A tiny, blazing fast SvelteKit todo list app. Built with Svelte 5 runes, no backend (persists to localStorage), and a minimal client JS bundle for near-instant interactions.

## Developing

```sh
npm install
npm run dev -- --open
```

## Building

```sh
npm run build
npm run preview
```

Deployed on Vercel via `@sveltejs/adapter-vercel`.
